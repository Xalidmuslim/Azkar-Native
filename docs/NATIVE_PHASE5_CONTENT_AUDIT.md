## Review decisions

- `by-you`: legacy morning/evening endings were not copied. Production uses the period-specific wording verified in Jami at-Tirmidhi 3391: Morning ends with `المصير`, Evening with `النشور`.
- `bismillah-protection`: production counter is 1 by the canonical project decision. The note explicitly preserves the fact that well-known primary reports contain 3 repetitions and that other hadith specialists accepted/strengthened that transmission.
- `pleased`: no single morning/evening isnad is presented as uncontested.
- `perfect-words`: count=1 is kept separate from the distinct report of 3 evening repetitions. A universal Tirmidhi hadith number is intentionally not asserted because numbering differs by edition/site.
- `muawwidhat`: count=3 remains canonical while the project-level isnad-disagreement metadata is retained.
- `baqarah-last-two`: wording is described as a night practice; the source is not paraphrased as if it literally called the verses morning/evening adhkar.
- `tahlil-ten`: it remains separate from the 100-times daytime hadith.
